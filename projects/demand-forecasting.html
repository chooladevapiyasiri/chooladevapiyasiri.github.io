Project Overview

A modular machine learning pipeline engineered to forecast next-week sales volume for high-velocity product categories (Grocery, Beverages, Chilled) across five supermarket outlets.

Designed around real retail supply chain dynamics, this system replaces static reordering rules with data-driven demand projections—enabling store managers to optimize inventory levels, reduce stockouts, and minimize holding/spoilage costs.

Strategic Business Impact: Replaces rigid replenishment rules with granular demand projections, preventing revenue loss from stockouts on FMCG lines while curbing capital lockup and perishable spoilage.

1. Exploratory Data Analysis & Driver Identification

Before model construction, statistical hypothesis testing and time-series decomposition were conducted to uncover underlying demand signals:

  • Weekly Seasonality: Identified consistent intra-week purchasing surges concentrated in specific categories.
  • Store Inter-variance: Mapped baseline demand variations across all five physical locations.
  • Category Dynamics: Standardized tracking across top fast-moving lines (Grocery, Beverages, Chilled).

2. Pipeline Architecture & Sequential Design

Rather than a single monolithic notebook, the solution is broken into a sequence of numbered, single-purpose notebooks under src/ — each handling one stage of the pipeline, from raw preprocessing through feature engineering to model training — with shared logic and orchestration centralized in a utils/ module::

src/
├── model/    # Numbered, sequential notebooks: preprocessing → primary key
│             # & target creation → feature engineering → master table →
│             # encoding → pipeline fitting → train/test split →
│             # model training → feature importance
└── utils/    # Data-source loading scripts, shared utility functions,
              # and a run_script notebook that orchestrates the sequence

3. Granular Key Modeling & Metric Alignment

Prediction Target: Next-week aggregate sales (t+1).

Data Granularity: Modeled strictly at the [Outlet ID] | [Item Category] | [Week] level to align directly with real-world inventory ordering cycles.

Evaluation Framework: Evaluated using Mean Absolute Percentage Error (MAPE) at the exact operational key level, ensuring errors reflect individual store-level stock risks rather than masked global averages.

Key Insights & Engineering Trade-offs

  • 01
    Operational Key Alignment vs. Global Aggregation: Evaluating models at the strict [Outlet | Category | Week] key level prevented high-volume stores from masking severe stockout risks in smaller locations.
  • 02
    Sequential Notebooks vs. Monolithic Script: Splitting preprocessing, key/target creation, feature engineering, and model training into numbered, single-purpose notebooks made each pipeline stage independently inspectable and easier to debug in isolation, compared to one large end-to-end script.
  • 03
    Lag & Rolling Statistics Integration: Constructing multi-week rolling statistics captured underlying momentum far more effectively than relying solely on point-in-time historical lags.

Planned Roadmap & Technical Extensions

  • Exogenous Drivers: Incorporating promotional calendars, discount pricing signals, and localized weather metrics into feature generation.
  • Advanced Estimators: Upgrading baseline regressors to Gradient Boosted Decision Trees (XGBoost, LightGBM).
  • Hierarchical Forecasting: Implementing top-down and bottom-up reconciliation techniques across global, regional, and store-specific tiers.
  • Production Deployment: Packaging the scoring pipeline into a REST API for automated, real-time demand-forecast inference.
