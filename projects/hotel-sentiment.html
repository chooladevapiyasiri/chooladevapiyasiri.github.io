Project Overview

Hospitality groups face a common challenge: massive volumes of guest feedback scattered across online platforms, offering rich insights buried in unstructured text.

This project processes 5,000+ TripAdvisor reviews to identify top-performing properties, locate core operational friction points, and isolate specific drivers of guest satisfaction (room quality, dining, staff performance, location).

Business Impact: Provides executive-level clarity that hospitality managers can use directly to prioritize capital improvements, refine staff training, and shape targeted marketing campaigns.

1. Data Pipeline & Automated Labeling

Cleaned, tokenized, lemmatized, and stripped noise/stopwords to yield a refined core dataset of 5,320 reviews. Developed an ensemble multi-tool sentiment pipeline to auto-annotate the dataset in the absence of ground-truth labels.

2. Handling Real-World Class Imbalance

The auto-labeling pipeline revealed a severe real-world data skew where >97% of reviews were positive. Benchmark two primary mitigation strategies:

  • Algorithm-Level: Dynamic class-weight adjustments.
  • Data-Level: Synthetic Minority Over-sampling Technique (SMOTE).

3. Model Engineering & Benchmarking

Sparse (TF-IDF, CountVectorizer) and dense (Word2Vec, GloVe) feature representations were evaluated during the class-imbalance mitigation stage. For the final head-to-head benchmark, classical models (Logistic Regression, SVM, XGBoost) were trained on BERT [CLS] pooled embeddings extracted from a pre-trained bert-base-uncased model, then compared directly against an end-to-end fine-tuned BERT transformer.

4. Aspect-Based Sentiment Analysis (ABSA)

Applied BERTopic for unsupervised topic modeling to cluster reviews into distinct thematic categories (e.g., dining, front-desk service, room cleanliness) and layered sentiment classification within individual clusters.

Performance & Results

Fine-tuning the BERT transformer vastly outperformed every classical baseline model—even those augmented with pre-trained word embeddings—demonstrating superior feature extraction on highly imbalanced text.

Model / Approach Overall Accuracy Minority Class F1-Score
Logistic Regression + BERT Embeddings 94.71% 45.44%
SVM + BERT Embeddings 96.55% 50.70%
XGBoost + BERT Embeddings 93.63% 40.58%
Fine-Tuned BERT 98.87% 78.57%

Key Insights & Trade-offs

  • 01
    Transformer Resilience to Imbalance: Contextual embeddings captured nuanced negative signals far better than static embeddings or sparse vector spaces, making BERT far more resilient to the 97:3 class ratio.
  • 02
    Topic Modeling Limitations in Domain Alignment: Unsupervised BERTopic effectively surfaced dominant themes but occasionally lacked alignment with strict operational categories (e.g., confusing room amenities with lobby infrastructure).
  • 03
    Baseline Complexity vs. Latency: Classical models paired with BERT embeddings offered lower computational overhead than end-to-end fine-tuning, but still failed to achieve production-grade precision on minority negative feedback.

Operational Recommendations & Future Work

1. Guided Topic Modeling

Transition from purely unsupervised BERTopic to Semi-Supervised Seeded Topic Modeling (e.g., KeyBERT / Guided Topic Modeling) to lock topic boundaries strictly around standard hospitality Key Performance Indicators (KPIs).

2. Model Distillation for Production

Compress the fine-tuned BERT model via Knowledge Distillation (e.g., DistilBERT or ONNX Runtime quantization) to reduce inference latency and computational cost for real-time streaming dashboards.

3. Explainability & Auditing

Integrate Integrated Gradients or Attention Map Visualizations (SHAP/LIME) to highlight specific trigger words causing negative classifications for manager review.

4. Targeted Active Learning

Implement a human-in-the-loop active learning sampling pipeline to continuously ingest and annotate low-confidence negative reviews, progressively mitigating class imbalance over time.
