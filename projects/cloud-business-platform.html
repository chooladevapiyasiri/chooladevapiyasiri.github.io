Project Overview

An end-to-end cloud-native microservices platform and analytics architecture featuring a production-ready video game e-commerce store (Lugx Gaming).

The project bridges DevOps/MLOps infrastructure with business intelligence—containerizing independent services, automating zero-downtime Blue-Green deployments on Google Kubernetes Engine (GKE) via GitHub Actions, and piping real-time user telemetry (clicks, scrolls, session duration) into ClickHouse, AWS S3, and Power BI for executive dashboarding.

DevOps & MLOps Impact: Pairs zero-downtime continuous deployment pipelines with high-throughput OLAP analytics, allowing real-time user engagement tracking without impacting microservice response latencies.

1. Infrastructure & Continuous Delivery (CI/CD)

A production-ready Kubernetes setup paired with an automated deployment pipeline to ensure continuous availability:

  • Kubernetes Orchestration & Service Mesh: Tested locally using Minikube before deploying to Google Kubernetes Engine (GKE). NGINX Ingress Controller manages path-based routing, SSL/TLS termination, and load balancing across the decoupled Game Service (FastAPI + PostgreSQL), Order Service (FastAPI + PostgreSQL), and Analytics Service.
  • Zero-Downtime Blue-Green Pipeline: GitHub Actions workflow automates GCP authentication, Docker container builds, and static security vulnerability scanning on push.
  • Automated Cutover: Deploys new builds to an inactive staging color, runs automated health check integration tests against live endpoints, and updates NGINX routing rules for seamless traffic cutover with instant rollback capability.

2. Analytics Pipeline & Business Intelligence

Captures dynamic user interactions across the storefront to enable real-time operational visibility:

  • Event Ingestion: Ingests frontend clickstream events, scroll depth, page views, and session durations directly into ClickHouse for high-throughput OLAP querying.
  • Data Lake Export: Stages telemetry logs to Amazon S3 using an AWS SDK integration for decoupled storage.
  • Power BI Integration: Connects to the exported data layer to visualize event counts by type, page views by page, scroll depth distribution, and average session duration per page.

Security, Governance & Observability

  • 01
    Secrets Management & RBAC: Enforced least-privilege cluster access via Kubernetes RBAC, with sensitive credentials (GCP service keys, Docker tokens) secured using GitHub Secrets and branch protection rules restricting deployment to trusted contributors.
  • 02
    Automated Container Guardrails: Implemented static vulnerability scanning on Docker images within CI pipelines prior to registry pushes, enforced alongside protected main-branch deployment policies.
  • 03
    Centralized Cluster Observability: Configured Google Cloud Operations Suite (Stackdriver) for centralized cluster logging, resource metric monitoring, and distributed tracing across all active microservices.
